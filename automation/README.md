# Automated Ticketing

The SOC lab integrates Elastic Security with osTicket to automate incident ticket creation when detection alerts are generated.

## osTicket Connector

The Elastic osTicket connector is configured to communicate with the osTicket API.

![osTicket Connector Test](../evidence/automation/osticket-connector-test-success.png)

The connector test completed successfully, confirming connectivity between Elastic and the osTicket API.

## Automated Ticket Creation

Security alerts generated by the detection rules are forwarded to osTicket through the configured API integration.

![osTicket Ticket List](../evidence/automation/osticket-ticket-list.png)

The ticket list shows security incidents created in osTicket from the SOC workflow.
