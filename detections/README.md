# Detection Engineering

The SOC lab uses custom Elastic Security detection rules to identify brute-force authentication activity against the Windows and Ubuntu endpoints.

## SSH Brute-Force Detection

The SSH detection rule identifies repeated failed SSH authentication activity on the Linux endpoint.

The rule correlates failed authentication events and groups activity by source IP and username within a defined time window.

## RDP Brute-Force Detection

The RDP detection rule identifies repeated failed RDP authentication attempts against the Windows endpoint.

The rule uses Windows authentication telemetry and evaluates repeated failed logon activity associated with the RDP logon type.

## Detection Workflow

```text
Endpoint Telemetry
        ↓
Authentication Events
        ↓
KQL Detection Rules
        ↓
Threshold / Correlation
        ↓
Elastic Security Alert
        ↓
Investigation
        ↓
Automated Ticketing
```
